Политика конфиденциальности

SilentNet Uploader — служебное приложение для личного использования владельцем YouTube-канала SilentNet. Приложение не собирает и не передаёт данные сторонним лицам.

Что делает приложение

Через официальный YouTube Data API приложение загружает видеоролики на YouTube-канал SilentNet и оставляет под ними комментарий от имени того же канала. Больше приложение ничего не делает.

Какие данные используются

Приложение использует OAuth-токен доступа только к каналу своего владельца — для загрузки видео, чтения базовой статистики канала и публикации комментариев. Данные зрителей канала не запрашиваются и не хранятся.

Хранение данных

Токен доступа хранится в зашифрованном виде в приватном репозитории владельца на GitHub (GitHub Actions Secrets) и никому, кроме владельца, не доступен.
